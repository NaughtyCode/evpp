# P2-22: DNS Resolver shared_ptr RAII Improvement

**Date:** 2026-05-28
**Status:** Complete
**Plan:** `./docs/tasks/infra_plan/p2/p2-22-dns-leak-fix.md`

## Summary

Replaced the raw `new std::shared_ptr<DNSResolver>` + manual `delete` pattern in
`AsyncDNSResolve()` with `std::make_unique` + `.release()` for explicit ownership
transfer to the libevent C callback. No behavior change — all existing cleanup
paths (OnResolved, OnTimeout, Cancel, OnCanceled, destructor) continue to work.

## Changes

### Modified Files

| File | Change |
|------|--------|
| `src/runtime/evpp/dns_resolver.cc` | Replaced `new std::shared_ptr<DNSResolver>(p)` with `std::make_unique<...>(shared_from_this())` + `.release()` |

## Design Decisions

- **Minimal change**: Only the creation site changed. All delete paths remain
  the same — they still receive a raw pointer that must be manually freed.
- **Explicit ownership transfer**: `.release()` documents that ownership is
  transferred to the C callback (`evdns_getaddrinfo`), making the intent
  clearer than raw `new`.

## Acceptance Criteria

- [x] Raw `new` for `evdns_cb_arg_` replaced with `unique_ptr` ownership transfer
- [x] All existing cleanup paths continue to work
