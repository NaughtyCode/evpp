════════════════════════════════════════════════════════════════════════════════
                           启动流程 (Startup Flow)
════════════════════════════════════════════════════════════════════════════════

  main()
    │
    ├─[1] WinSockGuard (WSAStartup)
    │
    ├─[2] ConfigManager::Instance().Load("resources/config")
    │     ├─ engine.json  → EngineConfig { log, frame, scripts_dir }
    │     └─ server.json  → ServerConfig { http, msgpack }
    │
    ├─[3] Engine::Instance().Init(engine_config)
    │     ├─ InitLogger()             → Quill async logger
    │     ├─ ProfilerManager::Init()  → Perfetto tracing
    │     ├─ TimerManager::create_instance() + initialize()
    │     ├─ EventLoop creation       → libevent event_base
    │     ├─ ScriptVM creation        → luaL_newstate() + luaL_openlibs()
    │     ├─ PhysicsEngineBridge::Initialize() → (no-op when disabled)
    │     ├─ ScriptVM::DoDirectory("resources/script")
    │     │     └─ each .lua file → ScriptVM::DoFile()
    │     │           └─ may call require("net"), require("timer"), ...
    │     │                 → luaopen_* functions registered via
    │     │                   script::ExportAll() during VM init
    │     └─ ScriptVM::InitScript()   → calls global Lua OnInit()
    │
    ├─[4] Engine::Run()
    │     ├─ Engine::Start()
    │     │     ├─ frame_timer_ = loop_->setInterval(frame_interval)
    │     │     │     └─ each tick: Engine::FrameLoop()
    │     │     ├─ sigint_watcher_ (Ctrl+C handler)
    │     │     └─ sigterm_watcher_ (Linux only)
    │     │
    │     └─ loop_->Run()  →  blocks until Shutdown()
    │
    └─[5] ShutdownLogger()


════════════════════════════════════════════════════════════════════════════════
                        每帧循环 (Per-Frame Loop)
════════════════════════════════════════════════════════════════════════════════

  frame_timer fires
    │
    └─ Engine::FrameLoop()
         │
         ├─ TimerManager::update()
         │     ├─ HrTimerManager::process_expired()
         │     ├─ TimerWheel::advance()
         │     └─ AlarmTimerManager::process_expired()
         │
         ├─ PhysicsEngineBridge::Tick(frame_count, delta_time)  (if enabled)
         │
         └─ ScriptVM::UpdateScript()  →  calls global Lua OnTick()
               │
               └─ Lua scripts may:
                     ├─ send/receive network data (net module)
                     ├─ create/cancel timers (timer module)
                     ├─ log messages (log module)
                     ├─ pack/unpack msgpack (msgpack module)
                     └─ import other modules (import module)


════════════════════════════════════════════════════════════════════════════════
                      关键依赖关系 (Key Dependencies)
════════════════════════════════════════════════════════════════════════════════

  Engine
   ├─ owns → ScriptVM
   ├─ owns → EventLoop (or uses external)
   ├─ depends on → ConfigManager (singleton)
   ├─ depends on → TimerManager (singleton)
   ├─ depends on → PhysicsEngineBridge (singleton)
   └─ depends on → ProfilerManager (singleton)

  ScriptVM
   ├─ owns → lua_State* (Lua VM)
   ├─ owns → ScriptImporter (module loader)
   ├─ owns → CustomPtrStore (void* array)
   └─ registers → script::ExportAll() → 9 Lua modules

  EventLoop (libevent wrapper)
   ├─ used by → TcpServer, TcpClient, HttpServer, HttpcClient
   ├─ used by → UdpServer, UdpClient
   ├─ used by → KcpServer, KcpSyncClient
   ├─ used by → InvokeTimer (frame timer)
   └─ used by → SignalEventWatcher

  GameClient (optional C API)
   ├─ wraps → Engine (singleton)
   ├─ exposes → TCP, UDP, KCP, HTTP via opaque handles
   ├─ exposes → Timer (timeout, interval)
   ├─ exposes → Logging (6 levels)
   └─ exposes → Script (DoString, DoFile, RegisterFunction)
