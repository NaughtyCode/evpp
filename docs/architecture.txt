════════════════════════════════════════════════════════════════════════════════
                           启动流程 (Startup Flow)
════════════════════════════════════════════════════════════════════════════════

  main()
    │
    +-[1] ConfigManager::Instance().Load("resources/config")
    │     + runtime/runtime.json -> RuntimeConfig { log, frame, scripts_dir, sandbox }
    │     + server/server.json   -> ServerConfig { http, msgpack, admin_port, mongodb_*, db_service }
    │     + client/client.json   -> ClientConfig { scripts_dir }
    │     + MongoDB cluster configs (auto-loaded from paths in server.json)
    │     + DbServiceConfig (from db_service.json)
    │
    +-[2] Engine::Instance().Init(runtime_config, entry_scripts_dir, [external_loop])
    │     + InitLogger()              -> Quill async logger
    │     + ProfilerManager::Init()   -> Perfetto tracing
    │     + TimerManager::create()    -> non-singleton, owned by Engine
    │     + EventLoop creation        -> libevent event_base (if standalone mode)
    │     + ScriptVM creation         -> luaL_newstate() + luaL_openlibs() + sandbox
    │     + PhysicsEngineBridge::Init() -> (no-op when ENGINE_PHYSICS_ENABLED=OFF)
    │     + ScriptVM::DoDirectory(resources/script/runtime)  -> common runtime scripts
    │     + ScriptVM::DoDirectory(entry_scripts_dir)         -> role-specific scripts
    │     + ScriptVM::InitScript()    -> calls global Lua OnInit()
    │
    +-[3] Engine::Run()  [standalone mode]
    │     + Engine::Start()
    │     │     + frame_timer_ = loop_->setInterval(frame_interval)
    │     │     │     -> each tick: Engine::FrameLoop()
    │     │     + sigint_watcher_ (Ctrl+C handler)
    │     │     + sigterm_watcher_ (Linux only)
    │     │
    │     + loop_->Run()  -> blocks until Shutdown()
    │
    +-[4] Engine::Cleanup()  [ordered CleanupPhase]
    │     + CleanupPhase::PhysicsShutdown   -> stop physics VM + thread
    │     + CleanupPhase::DatabaseShutdown  -> stop DB threads + drain queues
    │     + CleanupPhase::NetworkShutdown   -> [REQUIRES script_vm_ alive]
    │     + CleanupPhase::TimerShutdown     -> [REQUIRES script_vm_ alive]
    │     + CleanupPhase::ScriptDestroyed   -> lua_close + lifecycle hooks
    │     + CleanupPhase::FinalLogs         -> GC stats, cleanup confirmation
    │
    +-[5] ShutdownLogger()


     [Library mode (host provides EventLoop)]

       engine.Init(config, entry_scripts, &external_loop);
       while (running) {
           external_loop_dispatch_pending();
           engine.Tick();   // timer update + Lua update, frame-rate limited
       }
       engine.Cleanup();


════════════════════════════════════════════════════════════════════════════════
                        每帧循环 (Per-Frame Loop)
════════════════════════════════════════════════════════════════════════════════

  frame_timer fires  [standalone]  OR  host calls Engine::Tick()  [library mode]
    │
    +- Engine::FrameLoop()
         │
         +- TimerManager::update()          [main thread timer mgr]
         │     + HrTimerManager::process_expired()
         │     + TimerWheel::advance()
         │     + AlarmTimerManager::process_expired()
         │
         +- PhysicsEngineBridge::FetchResult()
         │     + Dequeue PhysicsFrameResult from physics thread SPSC
         │     + Invoke PhysicsResultHandler callback
         │
         +- SpaceMessageRouter::ProcessPending()
         │     + Deliver cross-space messages
         │
         +- SpaceManager::ForEachSpace()
         │     + Each Space::Update(delta_ms) -> calls space's Lua OnTick()
         │
         +- ScriptVM::UpdateScript()         [main VM]
         │     + calls global Lua OnTick()
         │     + Lua scripts may:
         │           + send/receive network data (net module)
         │           + create/cancel timers (timer module)

════════════════════════════════════════════════════════════════════════════════
                      关键依赖关系 (Key Dependencies)
════════════════════════════════════════════════════════════════════════════════

  Engine
   + owns -> ScriptVM (main Lua VM)
   + owns -> TimerManager (main thread, injectable)
   + owns -> EventLoop (in standalone mode) or uses external (library mode)
   + owns -> AdminHttpServer
   + owns -> ScriptReloader + FileWatcher
   + depends on -> ConfigManager (singleton)
   + depends on -> PhysicsEngineBridge (singleton)
   + depends on -> ProfilerManager (singleton)
   + depends on -> EntityManager (singleton)
   + depends on -> SpaceManager (singleton)

  ScriptVM (one per Space + one main VM)
   + owns -> lua_State* (Lua VM)
   + owns -> ScriptImporter (module loader)
   + owns -> CustomPtrStore (void* array)
   + owns -> CoroutineScheduler
   + owns -> LuaSandbox
   + registers -> 20+ Lua modules via script::ExportAll()

  Space (isolated game world)
   + owns -> ScriptVM (per-space Lua VM)
   + owns -> Entity set
   + owns -> SequentialIdAllocator
   + owns -> Player connection map
   + uses -> SpaceMessageRouter for cross-space comms

  Entity
   + owns -> AttributeTable
   + owns -> Components (C++ type-erased + Lua named)
   + owns -> Timer references (auto-cancel on Destroy)
   + linked -> TCPConn (optional, for player entities)
   + linked -> PhysicsBody (optional, for physics-simulated entities)

  DBThread (per-thread, ENGINE_MONGODB_ENABLED)
   + owns -> EventLoop (dedicated std::thread)
   + owns -> TimerManager (per-thread)
   + owns -> DBScriptVM (per-thread Lua VM)
   + borrows -> MongoClient from MongoClientPool (exclusive pop/push)
   + SPSC queues -> moodycamel::ConcurrentQueue<DbRequest/Response>

  PhysicsThread (ENGINE_PHYSICS_ENABLED)
   + owns -> EventLoop (dedicated std::thread)
   + owns -> TimerManager (per-thread)
   + owns -> PhysicsWorld (JoltPhysics)
   + owns -> PhysicsVM (Lua VM for collision callbacks)
   + condition_variable wake on command enqueue
   + SPSC queues -> moodycamel::ConcurrentQueue<PhysicsCommand/FrameResult>

  EventLoop (libevent wrapper)
   + used by -> TcpServer, TcpClient, HttpServer, HttpcClient
   + used by -> UdpServer, UdpClient
   + used by -> KcpServer, KcpSyncClient
   + used by -> InvokeTimer (frame timer)
   + used by -> SignalEventWatcher

  GameClient (optional C API)
   + wraps -> Engine (singleton)
   + exposes -> TCP, UDP, KCP, HTTP via opaque handles
   + exposes -> Timer (timeout, interval)
   + exposes -> Logging (6 levels)
   + exposes -> Script (DoString, DoFile, RegisterFunction)

  ConfigManager features:
    - glaze auto-reflection (C++23) for JSON <-> struct mapping
    - Thread-safe config access (shared_mutex)

    - MongoDB cluster config auto-loading (from paths in server.json)
    - Config validation on load (preserves old values on failure)

  Config struct hierarchy:
    RuntimeConfig
     + LogConfig (dir, level, rotation_size_mb, max_backup_files, format_pattern,

    ServerConfig
     + HttpConfig (timeout_sec)
     + MsgpackConfig (max_nesting_depth, max_payload_size)

     + MongoDbConnectionConfig (uri, hosts, replicaSet, directConnection, options)

     + MongoDbSecurityConfig (authentication, tls, bindIp)
